# yubingjian.github.io

Personal site for Yubing Jian, built with Jekyll and the Minimal Mistakes remote theme.

## Publish with GitHub Pages

1. Create a GitHub repository named `yubingjian.github.io` under the `yubingjian` account.
2. Push this repository to the `main` branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. GitHub Pages will build the site and serve it at `https://yubingjian.github.io`.

Before publishing, replace the placeholder LinkedIn, GitHub, and email links in `index.md` with your public contact details.
